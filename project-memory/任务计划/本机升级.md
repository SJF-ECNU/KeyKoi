# 本机升级

用当前工作树升级既有 macOS 安装，保留数据、监听地址、运行权限与 Touch ID 签名助手。仅迁移有实际用途的代理授权。

1. 备份密文库、旧二进制与适配器，先构建新版 CLI 和 daemon。
2. 替换正式安装的程序和适配声明，重启现有 launchd 服务。
3. 在本机终端交互解锁，切换旧 SSH Agent；检查服务、库、绑定、授权和 shim。
4. 绘制并检查简单架构图，记录结果。

四步已完成。库校验通过，客户端和后台二进制与当前工作树构建一致，已有授权、绑定和 shim 保留。控制台返回 200，已有 SSH 公钥可通过新版 Agent 枚举。Touch ID 助手签名有效，密钥库未登记 Touch ID。
