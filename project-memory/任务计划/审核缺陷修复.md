# 审核缺陷修复

关联工作流 [[project-memory/工作流/审核缺陷修复]]；缺陷清单与证据来自 [[project-memory/任务计划/全项目代码与功能审核]]。变更规范为 [[openspec/changes/review-remediation/proposal]]（proposal、design、specs、tasks 齐全）。

## 目标、范围与方案

把 2026-11-20 审核登记的 15 项 P1 与 19 项 P2 全部落到源码，走 OpenSpec 变更流程（`review-remediation`），并保持对外命令、路由与配置兼容。

- 范围：`internal/{broker,daemon,ssha,ipcclient,remoteauth,vault,store,central,tlsproxy,dbproxy,mysqlproxy,mongoproxy,redisproxy,oauth,integration,gateway,model,runner,shim,osruntime,signer}`、`cmd/keykoi*`、`packaging/macos`、`tests/acceptance` 中受影响的验收。
- 方案：把「授权判定」与「取值、转发」绑定到同一次授权快照；把代理的用钥决定交回主服务；密钥库补独立根密钥校验块与原子轮换；中心分离注册与管理凭据；OAuth 默认 HTTPS 且禁止跳转；CLI 秘密字段改为隐藏输入。
- 完成条件：`go build ./...`、`go vet ./...`、`go test ./...`、`go test -race ./...` 通过；受影响 shell 验收回归；任务清单按证据勾选。
