# 仓库整理与版本库建立

关联工作流 [[project-memory/工作流/仓库整理与版本化]]。

## 目标、范围与方案

此前仓库只有本机文件、没有版本元数据（多份记录写作 `branch: unavailable`、`commit: null`）。本任务把当前工作树整理成可维护的仓库，并按模块做细粒度提交，使后续接手能按提交定位变更。

- 范围：仓库根目录、`.gitignore`、各源码目录、文档与项目记忆、验收脚本、macOS 打包脚本。
- 不进版本库：可由源码重建的二进制与 Xcode 衍生数据、本机运行状态（socket/pid/日志/管理令牌/数据目录）、密钥库与备份文件。
- 方案：先定忽略规则，再按依赖顺序分模块提交（骨架 → 文档与记忆 → 规范与模块定义 → 核心类型 → 存储 → 密钥库 → 授权 → IPC → 交付通道 → 签名 → 后台 → 代理 → 接入与中心 → CLI → 前端 → 打包 → 验收）。
- 完成条件：工作树干净、`git log` 可按模块阅读、提交后的树仍 `go build/vet/test` 通过且 `openspec validate --all --strict` 通过。
