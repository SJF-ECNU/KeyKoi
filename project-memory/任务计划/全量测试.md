# 全量测试

[[project-memory/工作流/全量测试|对应工作流]]

## 目标与范围

在本机临时环境验收当前工作树。核对构建、功能效果、延迟、吞吐、资源与能耗，记录安全发现和每项适用范围。延迟测试与功能验收错开，物理功率取决于本机采样权限。测试使用合成凭证，不改产品代码。

## 执行步骤与证据

1. 运行完整 Go 测试、竞态检测和可隔离的端到端验收。已完成，失败用例逐一复测，阿里云代理仍有 2 项兼容性问题。
2. 对比直连与代理。HTTP 与 Redis 的吞吐、延迟和资源消耗已记录。物理功率采样受管理员权限限制。
3. 扫描工具链和依赖，检查应用的传输和授权路径。已完成，记录 34 条调用路径公告及代码审查发现。

## 当前进度与下一步

初次结果见 [[docs/验收/2026-11-20-全量测试|全量测试报告]]。2026-11-21 已使用修补后的工具链和依赖完成 [[docs/验收/验收总览#2026-11-21 安全与易用性合并复测|合并复测]]，依赖扫描无发现。下一次在独立负载条件下复测 HTTP 代理和能耗。
