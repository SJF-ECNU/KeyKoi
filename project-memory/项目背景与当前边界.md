# 项目背景与当前边界

## 目标与范围

预期使用者是需要调用既有 CLI 或 HTTP 工具的人、Agent 和脚本。受托管的业务凭证组合以指定数据库为唯一权威持久来源，进入 SQL 前在应用层加密。原平台负责业务权限。一版计划由单机后台、管理 CLI 和本机 Web UI 交付，MCP 是后续可选入口。

模型服务 API Key 已退出产品范围。通用 API Key 仍用于非模型业务，现有凭证按历史数据保留。

## 交付模式与可信范围

- `proxy` 由中介向登记上游完成认证，原工具无需取得真实值。
- `sign` 由中介保管密钥，原工具取得签名结果。
- `runtime_delivery` 把真实值交给原工具，必须明确标记交付范围；对工具自行复制、输出或转发凭证的行为无法做通用保证。
- 工具兼容状态需按工具版本、操作系统、适配器版本和运行环境验证。普通同账户进程的隔离能力、交换空间和转储行为也需实测。
