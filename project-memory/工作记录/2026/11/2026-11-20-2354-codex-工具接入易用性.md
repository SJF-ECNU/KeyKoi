## 任务计划书与目标

## 结果、改动与验证

- IPC 连接失败时提示检查后台状态和离线列出工具记录。KeyKoi 接入后，需要独立查看阿里云本地配置或版本时，使用登记的原工具路径。保留 shim 现有的参数、隔离和授权行为。
- 安装警告直接给出原工具路径，按实际 JSON 逐个 profile 检查明文 AccessKeySecret，未记录具体值。
- 撤销接入遇到配置漂移时返回原 `CONFIG_DRIFT`，补充文件、区段、字段和恢复路径。
- `go test ./internal/shim ./internal/integration ./cmd/keykoi` 通过。使用临时数据和受控上游，真实 aliyun-cli 3.5.3 的 shim 32/32、显式运行 12/12，真实 AWS CLI 2.41.0 接入 22/22。阿里云受控端点比对测试 AccessKeyId，观察到签名和会话令牌字段。原本正在运行的服务未被重启。
