# 走 OpenSpec 流程修复全部审核缺陷

## 任务计划书

[[project-memory/任务计划/审核缺陷修复]]，执行清单为 [openspec tasks.md](../../../openspec/changes/review-remediation/tasks.md)。本次推进第 1–10 组全部条目。

## 结果

按[审核结论](../../../任务计划/全项目代码与功能审核.md)的 15 项 P1 与 19 项 P2，建立 OpenSpec 变更 `review-remediation`（proposal、design、specs、tasks 四件套，`openspec validate --strict` 通过）并全部落地。

主要结果：

- 授权边界：`/v1/resolve` 只服务 `runtime_delivery`；新增 `/v1/ssh-sign-material`（sign + `ssh_key` + 字段白名单）；Broker 在交付前重校验会话、代次、授权、绑定与凭证版本；验证状态只在重校验通过后写入缓存；中心按主体／方式／版本裁定并只约束「本机领先于中心」的轮换；`once` 无会话验证改为一次性交换；路由与授权唯一。
- 代理：TLS 代理改为经本机 IPC 请求授权（不再自行解锁），四个数据库代理只用同一次授权返回的绑定快照；Redis/MySQL 上游默认 TLS；Redis 认证前解析设上限；MySQL 切 TLS 保留预读字节；关闭限时排空。
- 密钥库：备份拒绝覆盖运行库并原子替换；恢复先完整校验再事务替换；每个库保存独立根密钥校验块；轮换单事务完成；恢复同步清空审计与接入状态并留一条说明。
- 中心：设备注册与管理凭据分离，非回环监听要求 TLS，代次过期与真正撤销区分并只做一次有界重试。
- OAuth：默认 HTTPS、令牌交换禁跳转（回环需显式开关）、回调不复活管理员停用。
- 接入：备份只加密保存受管字段，撤销只还原受管字段；含空格路径按 shell 规则引用；验证走运行路径并核对用钥记录。
- CLI/运行器/shim：Unix 监听不替换存活 socket；shim 与主 CLI 共用数据目录；SSH Agent 会话可续期且枚举与用钥同源；`--` 后参数保留、交互进程移交前台、信号退出码 128+n；秘密字段支持隐藏输入与 stdin。
- 网关与签名：验证失败映射 401/403；路径按规范化双解释判定、响应中断记失败；静态 AccessKey 可签名且不带 Security-Token。
- macOS 安装：部署前严格校验候选签名与描述文件，失败保留原安装，状态检查失败传播；钥匙串重新登记先写新项。

验证：`go build ./...`、`go vet ./...`、`go test ./...`、`go test -race ./...` 全绿（21 个有测试的包）。受影响的可执行验收全部通过：p0 14/14、p1-management 24/24、p1-runtime 18/18、p1-integration 19/19、p3-central 15/15、p4-database-proxy 15/15、db-auth-proxies 12/12（MySQL/Mongo 因无 docker 跳过）、p4-tlsproxy 24/24、p4-ssh 32/32、p4-signer 21/21、tencent-huawei-signer 27/27、p4-oauth 41/41、oauth-client-credentials 28/28、keys-matrix 18/18、ui-login 30/30、git-no-plaintext 10/10、shim-aliyun 28/28、tool-aliyun 12/12、biometric-auth 65/65；macOS 安装自检 79 项。
