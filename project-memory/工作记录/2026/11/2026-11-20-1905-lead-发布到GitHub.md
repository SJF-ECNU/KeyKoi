# 发布仓库到 GitHub

## 任务计划书与目标

## 结果、改动与验证

- 用 `gh repo create KeyKoi --public --source=. --remote=origin --push` 创建 <https://github.com/SJF-ECNU/KeyKoi>（公开，默认分支 `main`），并补主题 `go`、`macos`、`credentials`、`secret-management`、`security`。
- 首次推送被 GitHub 推送保护拦下：`internal/signer/tencent_test.go` 的腾讯云文档示例 SecretId 命中「Tencent Cloud Secret ID」规则（注释与常量两处）。该值不参与签名计算，改为占位符 `AKIDkeykoi-doc-example-secret-id`，保留常量名与文档说明。
- 由于该字符串位于引入签名模块的提交里，用 `rebase -i` 对该提交 `edit` + `--amend` 后继续 rebase，重写本地历史再推送；此后 14 个提交哈希顺延，当前基线为 `e94d33f`。
- 推送成功后 `git rev-list --count origin/main` 为 20，`git status -sb` 显示 `main...origin/main` 无差异；`go build ./...`、`go test ./...`、`openspec validate --all --strict` 在重写后仍通过。
