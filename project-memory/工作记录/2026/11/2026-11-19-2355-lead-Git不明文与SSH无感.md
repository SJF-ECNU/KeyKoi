# Git 不明文交付与 SSH 无感入口

## 任务计划书与目标

用户明确核心要求为“无感 + 不明文给出”，重点覆盖 Git 与 SSH。对应 [[project-memory/任务计划/OpenSpec任务实现]] 的扩展工作。

## 结果、改动与验证

- 网关支持从 `Authorization: Basic base64(user:kks_…)` 识别中介令牌（git 只会用 Basic），转发前剥离并注入真实 Basic；401 响应带 `WWW-Authenticate` 以便凭据助手重试。
- 新增 `keykoi helper git-token`：只创建会话并输出 `username=keykoi` + `kks_` 令牌，不接触真实仓库凭据。
- 新增 `keykoi git setup/teardown`：把 `https://<host>/` 重写到本机网关路由，并配置仅返回中介令牌的凭据助手；git 配置里没有明文密码。
- SSH：agent 默认 socket 改为数据目录下固定路径，新增 `--write-shell-env` 写入受管 `SSH_AUTH_SOCK` 片段，私钥仍只在中介内签名；与 shim 共用受管 shell 块机制（按 tag 区分）。
- 验收：`tests/acceptance/git-no-plaintext.sh` 10/10（真实 `git clone` 成功、仓库从未见到 `kks_`、配置无明文、teardown 后恢复原生行为）；`go test ./internal/gateway` 通过。
- 并行进展：OAuth client_credentials/JWT 已完成（28/28）；腾讯/华为签名、Redis/MySQL/Mongo 代理仍在进行。
