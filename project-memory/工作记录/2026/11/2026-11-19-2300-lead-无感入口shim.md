# 无感入口（PATH shim）适配

## 任务计划书与目标

[[project-memory/任务计划/OpenSpec任务实现]]：给真实工具加无感入口，用户不再需要 `keykoi run` 前缀。以 aliyun-cli 3.5.3 为验证工具。

## 结果、改动与验证

- 新增 `internal/shim`：安装记录（0600，只含真实二进制绝对路径、Binding、环境映射、socket；不含凭证）、`<数据目录>/shims/<name>` 符号链接指向 keykoi、按 `argv[0]` 识别 shim、与 `keykoi run` 共用 Runner/IPC/许可路径。
- 新增 `keykoi shim install|list|remove`：安装前预检 Binding 与 `runtime_delivery` 许可；`--update-shell` 用受管标记写入 PATH 片段（幂等，可移除）；拒绝 shim keykoi 自身或相对路径，避免递归执行。
- 本地命令（`version`、`--help` 等）不取凭证直接透传，daemon 不在时仍可用；需要凭证的命令在 daemon 不可用时给出明确错误。
- Runner 调整：取消信号先按收到的信号转发（保留 SIGINT→130 交互语义），400ms 后 SIGTERM、`CancelGrace` 后 SIGKILL 兜底。
- 验收：`go test ./internal/shim`（3 项）；`tests/acceptance/shim-aliyun.sh` 19/19（PATH 解析、直接执行、AccessKeyId 匹配、签名、SecurityToken、令牌不泄露、参数保真、退出码、递归拒绝、离线帮助命令、daemon 故障、移除还原）。结果在 `docs/验收/artifacts/shim-aliyun/result.json`。
- 回归：`go test ./...`、P0、P1 runtime、P1 management、阿里云 CLI 直接路径均通过。
