# 接入 gh 并恢复阿里云 CLI

## 任务计划书

沿用 [[openspec/changes/local-activity-and-subject-grants/design|主体与授权设计]]，在已安装本机实例配置两个工具的凭证、绑定、账户级运行时交付许可与命令入口。

## 结果

- 将 GitHub CLI 已登录凭证和用户新提供的阿里云凭证分别存入 KeyKoi。使用绑定 `github-cli` 和 `aliyun-cli`，授权范围为本机账户及对应绑定的运行时交付，策略为每个会话验证一次。
- 通过 KeyKoi shim 接管 `gh` 和 `aliyun`。新交互 zsh 使用管理的 PATH 配置，现有终端可经本机命令链接进入。阿里云使用运行时注入，默认地域 `cn-hangzhou`。
- 在用户提供新 AK/SK 后停止之前等待的阿里云 OAuth 初始化，未生成原生 CLI 配置。

## 验证与后续

- KeyKoi 管理的 `gh` 调用 GitHub 用户接口成功，`aliyun sts GetCallerIdentity` 返回有效身份响应。终端只显示成功标志。
- 新 zsh 解析到两个 shim。两个绑定均有允许且成功交付的审计元数据，活跃许可使用会话级验证。
- 日常直接使用原命令，新的会话遵循现有系统验证策略。
