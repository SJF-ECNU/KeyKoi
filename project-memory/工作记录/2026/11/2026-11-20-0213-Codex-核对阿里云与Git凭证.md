## 结果与验证

- LaunchAgent 正在使用安装前缀下的 `data/vault.db`。读取凭证元数据时仅见一条有效 SSH 密钥。当前终端的 KeyKoi SSH agent 可枚举一条身份。

- 历史阿里云和 Git HTTPS 验收使用隔离的临时数据和受控上游，不能作为真实账号曾导入的证据。
