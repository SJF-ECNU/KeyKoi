# 完成用钥边界与执行许可重构

## 任务计划书与目标

[[openspec/changes/use-lease-execution/design]]。完成执行清单 1.1–2.1。

## 结果、改动与验证

- HTTPS、PostgreSQL、Redis、MySQL 和 MongoDB 监听器由 daemon 启动，按实际调用会话鉴权，只使用 `proxy` Grant；启动 IPC 只返回监听信息。
- Broker 保留原许可直到连接或请求结束；锁库、会话和授权撤销取消执行，数据库复核绑定和原中心许可，本地计时限制许可到期。
- SSH 维持签名结果接口；元数据查询无须解密；`runtime_delivery` 支持绑定级字段白名单，省略字段时沿用旧绑定配置。数据库与 SSH 支持原生协议地址。
- 构建、vet、Go 全量测试、race、OpenSpec strict 通过。五套验收共 120 项通过，包括真实 Redis 撤销后断开已有连接。细项计数见 [[openspec/changes/use-lease-execution/tasks]]。
