# 本机凭证边界加固

## 任务计划书与目标

执行 [[openspec/changes/harden-credential-boundaries/design]] 的 1.1–1.4。使用当前 macOS 的隔离测试目录、临时守护进程与合成凭证。

## 结果、改动与验证

- Go 最低版本为 1.26.11，x/crypto 为 v0.59.0。模块下载沿用 Go 官方代理，校验记录由第三方中转，Go 正常验证官方签名。模块整理、`go mod verify` 与临时 CLI、daemon 构建通过。govulncheck v1.10.0 使用 2026-11-11 更新的 Go 漏洞库，`./...` 与 `./cmd/...` 均无发现。上一轮两个范围各报告 34 条调用路径公告。
- IPC 会话关闭与许可撤销要求调用方为对象所属 KeyKoi 主体或具有管理权限，完整审计读取要求管理权限。普通主体以 Unix peer 推导的身份执行。定向用例覆盖同主体清理、管理员清理、跨主体拒绝和审计权限。实机 Unix IPC 创建并关闭了普通会话，管理 CLI 的 `audit` 查到了撤销记录。系统用户仍是文件访问边界，持有同 UID 文件权限的进程可读取本机管理令牌。
- MongoDB 上游默认验证 TLS 证书链与登记主机名。真实 Redis、MySQL 和 MongoDB 验收 36/36 通过，含使用私有 CA 的 MongoDB 请求、未知 CA 拒绝且无需降级，以及显式明文兼容。Go 定向测试和 OpenSpec strict 校验通过。
- 汇总全量测试曾发现现有 MySQL 测试上游预读 TLS 数据的问题，由总任务在该 fixture 中修复并复测。
