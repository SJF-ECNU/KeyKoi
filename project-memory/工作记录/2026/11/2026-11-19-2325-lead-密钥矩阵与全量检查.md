## 结果、改动与验证

- 阿里云明文配置：本机 `~/.aliyun/` 只有 logs/plugins/telemetry，没有 `config.json`，无需清理；shim 的 `--config-path` 隔离仍然保留，安装时会对未来出现的明文 profile 报警。
- 网关：除 `Authorization: Bearer` 与 `X-Api-Key` 外，新增识别 `X-Goog-Api-Key`、`Api-Key` 携带的中介令牌，并在转发前剥离这些头；binding 可用 `auth_header` 指定真实注入头。
- 凭证助手：`keykoi helper git` 支持 git 追加的位置参数动作（`get|store|erase`），可直接配置为 `credential.helper`。
- 新增验收 `tests/acceptance/keys-matrix.sh`（14/14）：
  - OpenAI 官方 Python SDK 2.24.0 经网关调用 `/v1/chat/completions`，上游收到真实 Bearer；
  - Anthropic 官方 SDK 0.84.0 经网关调用 `/v1/messages`，上游收到真实 `x-api-key`；
  - Gemini 风格 `x-goog-api-key` 携带中介令牌，上游收到真实值；
  - Basic 凭据注入正确；
  - 真实 `git credential fill` 返回正确用户名/令牌，且不泄露中介令牌；
  - 无会话 401、未登记路由 404、上游从未见到中介令牌。
- 新增受控上游能力：OpenAI/Anthropic 兼容响应、`--expect-header` 精确匹配与统计、`header_matched`。
- 全量检查：`go test ./...`、`go vet ./...`、`openspec validate --changes --strict` 与全部 13 个验收脚本全部通过（结果见 `/tmp/full-check.log` 对应产物与 `docs/验收/artifacts/`）。
