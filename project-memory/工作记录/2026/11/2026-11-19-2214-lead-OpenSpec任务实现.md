# 按 OpenSpec 逐一实现 P0–P4

## 任务计划书与目标

[[project-memory/任务计划/OpenSpec任务实现]]，推进步骤 1–11：把 15 个变更中的 13 个实现并在本机 macOS 验收，Linux 两项按路线图延期。

## 结果、改动与验证

- 建立 Go 模块 `keykoi`：`cmd/keykoi`、`cmd/keykoid`、`cmd/keykoi-central`，`internal/{model,secret,store,vault,broker,gateway,helper,runner,ipcclient,osruntime,integration,daemon,measure,central,ssha,signer,oauth,dbproxy,tlsproxy}`，`adapters/`、`web/`、`packaging/macos/`、`tests/{acceptance,fixtures}/`。
- P0：四个核心对象与三种期限、内存 Broker、显式网关、真实 AWS CLI `credential_process` Helper、直连/代理测量。验收 `tests/acceptance/p0.sh` 14/14；实测代理 TTFB p50 0.213ms、直连 0.088ms，流式首块 0.172ms 先于 485ms 完整响应。
- P1：SQLite 加密密钥库（Argon2id + AES-GCM 信封、并发版本完整读取、密文备份恢复与待复核）、受认证 IPC 会话与 Grant/UseLease、生产网关（Bearer/API Key/Basic、路径编码与流式）、Helper 与子进程环境交付（取消、异常、残留清理、双账户、轮换、重启）、适配器接入（严格 Manifest、脱敏预览、幂等应用、真实验证、漂移、版本范围、撤销）、管理 CLI/Web UI/launchd 安装。
- P3：PostgreSQL 中心、设备注册与签名租约、在线确认、短期离线窗口、撤销事件、代次轮换与 `LEASE_STALE` 版本切换。验收 `tests/acceptance/p3-central.sh` 15/15。
- P4：SSH agent（真实 sshd 与 `ssh-keygen -Y`）、SigV4 签名（官方向量 + 受控校验上游 + AWS CLI 对照）、OAuth 授权码+PKCE+轮换刷新、PostgreSQL 协议代理、受信 HTTPS 代理（真实 curl）。各验收脚本 15–41 项检查通过。
- 验证边界：全部为本机拓扑；TLS 代理支持 HTTP/1.1、不支持证书固定；数据库代理仅 PostgreSQL；P3 的休眠与显著时间偏差未单独注入；Linux 与 Windows 未验收。
- 证据：`docs/验收/验收总览.md`、`docs/验收/artifacts/*/result.json`、`go test ./...`。
