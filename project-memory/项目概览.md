# KeyKoi 项目概览

钥鲤 KeyKoi 计划把散落在配置里的业务凭证收进加密密钥库，让人、Agent 和脚本继续使用原工具，由中介控制凭证何时、以何种方式交给谁使用。

## 当前实现状态

2026-11-19：P0、P1 六项、P3 与 P4 五项已实现并在本机 macOS 验收（证据见 [[docs/验收/验收总览|验收总览]]）；Linux 文件专项（P0/P2）与 Windows 延期。组件与职责如下，实际代码位置见 [[project-memory/环境与部署|环境与部署]]。

## 组件

| 组件 | 职责 |
| --- | --- |
| 本机后台服务 `keykoid` | 解锁与管理密钥库，检查会话和授权，调度认证或交付 |
| 管理命令 `keykoi` 与本机 Web UI | 录入、接入预览、诊断、锁定与撤销 |
| 密钥库与 Runtime Broker | 加密存储，按许可读取同一版本的凭证组合 |
| 适配器、网关、签名器和运行器 | 接入原工具，执行认证注入、签名或运行时交付 |
| 审计与接入管理 | 记录使用元数据，管理工具配置变更与生命周期 |

实现采用单一 Go 后台进程承载核心逻辑，按模块组织；设计依据见 [[KeyKoi_Implementation_Plan_v0.1#14. 技术选型与代码组织|实施草案第 14 节]]，阶段划分见 [[KeyKoi_Implementation_Plan_v0.1#16. 分阶段开发计划|实施草案第 16 节]]。
