## 目标、状态与最新结果

阿里云 shim 现在会在 IPC 连接失败时指向 `keykoi status` 和离线 `keykoi shim list`。原生版本和本地配置从该列表找到的工具绝对路径执行。安装警告按 profile 检查明文配置。AWS 受管字段漂移时，撤销明确指出配置位置，并保留用户编辑。

真实阿里云 CLI 3.5.3 的 shim 和显式运行分别通过 32/32、12/12。真实 AWS CLI 2.41.0 接入验收通过 22/22。
