# 使用看板与主体授权

## 任务计划书

[[openspec/changes/local-activity-and-subject-grants/design|OpenSpec 设计与计划]]。

## 当前状态

已实现本机用钥看板、账户和代理主体授权、通用 Agent 登记。真实 Codex App、Codex CLI、Claude Code 和通用原生进程链通过本机验收。

看板新增一键登录入口：`keykoi ui [--admin ADDR] [--no-open]` 读 `<数据目录>/admin.token`，拼 `http://<admin>/#token=<token>` 交给系统浏览器；页面加载时读 `location.hash` 的 `token=`、填入登录框并自动连接，随后立即 `history.replaceState` 清除 hash。令牌不进请求行、Referer 或访问日志，默认模式也不写 stdout/stderr。验收：`ui-login.sh` 30/30。

## 阻塞与下一步

实现与本机验证已完成。日常从 [[docs/指南/使用看板与授权|使用指南]] 打开管理页和查询用钥主体。
