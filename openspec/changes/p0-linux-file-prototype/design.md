# P0 · Linux 私有内存文件原型设计

> **延期**：本轮验收范围为本机原生 macOS。此 Linux 变更保留为后续规划，当前暂停实现与验收。

## Context

固定路径工具可能在配置旁写缓存，或通过临时文件和重命名更新配置。需要在 Linux 验证目录级视图与清理能力。

## Goals / Non-Goals

用实际 Linux 环境和小型测试工具验证文件系统行为，真实固定路径 CLI 的接入由 P2 完成。

## Decisions

- 在受管理的进程视图覆盖整个配置目录，使用生成的测试数据检查原子替换、邻接文件和宿主可见性。
- 记录运行用户、内核、挂载能力、交换与转储条件。能力不足时以不支持结束；文件页的处理只证明已测范围。
- 把进程取消和退出后的目录回收结果交给 P2，据此确定受支持的内核、权限和部署选项。

## Dependencies

无前置变更。前置变更提供的运行行为和相应验收证据用于本变更的实现与验证。全局顺序见[实施路线图](../../roadmap.md)。
