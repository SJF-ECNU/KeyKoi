## ADDED Requirements

### Requirement: 私有目录与文件语义

原型 SHALL 在真实 Linux 环境验证固定路径映射、原子重命名和邻接文件在受管理视图中的行为。

#### Scenario: 私有视图

- **WHEN** 两个受控运行使用同一个逻辑配置路径
- **THEN** 各自看到其映射数据，宿主原配置未变化，测试记录读写范围

### Requirement: 能力不足与回收

原型 SHALL 在能力不足时报告具体原因并拒绝内存模式，并记录退出与取消后的资源回收。

#### Scenario: 缺少约定能力

- **WHEN** 环境缺少所需挂载权限或无法满足该文件页安全要求
- **THEN** 原型报告不支持，未将配置降级写入普通磁盘目录
