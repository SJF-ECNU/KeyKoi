# P0 · Linux 私有内存文件原型执行清单

> **延期**：本轮验收范围为本机原生 macOS。此 Linux 变更保留为后续规划，当前暂停实现与验收。

验收依据为[规格场景](specs/linux-file-isolation-prototype/spec.md)。

## 1. 实现

- [ ] 1.1 准备与登记一套可实际执行的 Linux 环境，核对挂载、内存文件系统和所需权限。
- [ ] 1.2 以生成的数据验证固定路径、原子替换、邻接文件、两次运行隔离及退出回收。

## 2. 验收

- [ ] 2.1 在真实 Linux 运行正常、取消和能力缺失路径，记录状态、清理结果和 P2 所需能力。
- [ ] 2.2 明确区分原型证据、宿主级未验证项和真实工具待验证项。
