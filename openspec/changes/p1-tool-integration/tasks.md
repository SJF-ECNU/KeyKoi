# P1 · 适配声明、接入迁移与恢复执行清单

验收依据为[规格场景](specs/managed-tool-integration/spec.md)。本轮在当前 Mac 的原生 macOS 环境执行，见[验收口径](../../roadmap.md#验收口径)。

## 1. 实现

- [x] 1.1 实现 Manifest 严格解析、可信执行引擎注册和工具定位。
- [x] 1.2 实现脱敏预览、密文导入、按受管字段应用及验证，提供非交互入口诊断。
- [x] 1.3 实现失败恢复、停用、撤销和配置漂移识别。

## 2. 验收

- [x] 2.1 在隔离配置中运行接入成功、重复应用、并发修改、验证失败和撤销，检查无关字段及无明文副本。
- [x] 2.2 从真实工具接入证据核对展示字段，并模拟一次超出验证范围的版本升级。
