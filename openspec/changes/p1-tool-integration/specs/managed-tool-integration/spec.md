## ADDED Requirements

### Requirement: 可预览且可恢复的配置迁移

接入管理 SHALL 先给出脱敏预览，只修改受管字段，并将导入的凭证写入加密密钥库。

#### Scenario: 配置写入后验证失败

- **WHEN** 接入已修改配置但真实验证失败
- **THEN** 状态进入 recovery_required，无关字段完整，普通备份、临时文件及配置差异无真实凭证

### Requirement: 支持状态绑定实际环境

接入管理 SHALL 按版本、系统、适配器和运行环境记录验证状态，并准确显示真实值是否到达原工具。

#### Scenario: 工具更新或配置漂移

- **WHEN** 用户更新工具或修改受管认证字段
- **THEN** 接入状态回到待验证，无关手工修改不被覆盖
