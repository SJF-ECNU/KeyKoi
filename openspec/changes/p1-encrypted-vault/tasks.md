# P1 · 单机加密密钥库执行清单

验收依据为[规格场景](specs/encrypted-vault/spec.md)。本轮在当前 Mac 的原生 macOS 环境执行，见[验收口径](../../roadmap.md#验收口径)。

## 1. 实现

- [x] 1.1 建立 SQLite 数据模型和升级入口，使用事务写入版本并切换当前版本。
- [x] 1.2 实现加解密、手动解锁、锁定和元数据查询，区分不可解密、锁定和不可用等错误。
- [x] 1.3 实现密文备份与恢复，明确恢复元数据和授权复核如何传递给 Broker。

## 2. 验收

- [x] 2.1 用生成凭证运行持久化和并发轮换，检查数据库、WAL、备份和约定日志路径。
- [x] 2.2 验证重启后锁定、错误解锁、密文异常、旧备份恢复及复核前拒绝用钥。
