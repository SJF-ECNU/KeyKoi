# 本机控制台重建

工作流标识为 rebuild-local-console。执行与验收见 [tasks.md](tasks.md)。

采用固定节奏的桌面侧栏与窄屏顶栏，独立呈现活动、凭证绑定、授权与设置。空库提供初始化及后续步骤。保留本机管理令牌、已登记 Touch ID、主密码回退和授权验证策略。使用受控表单输入秘密，错误在当前视图显示，分区的读取失败各自可恢复。

安装版 CLI 应从安装目录发现运行中后台，显式 socket 与数据目录优先；一键登录应支持已打开的页面，管理令牌仍只驻页内存。先以独立密钥库完成 Chromium 实测，再升级本机正在运行的安装实例，并保留其数据和现有 LaunchAgent 配置。

Touch ID 的已登记标记是进程内观测。系统报告 Touch ID 可用时，重启后的锁定页仍提供尝试解锁和主密码入口。
