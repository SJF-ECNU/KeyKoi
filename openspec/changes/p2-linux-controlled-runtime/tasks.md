# P2 · Linux 受控文件运行与旧 CLI执行清单

> **延期**：本轮验收范围为本机原生 macOS。此 Linux 变更保留为后续规划，当前暂停实现与验收。

验收依据为[规格场景](specs/linux-controlled-file-runtime/spec.md)。

## 1. 实现

- [ ] 1.1 根据 P0 结论定义支持的宿主能力与受限辅助操作，实现两类内存配置路径。
- [ ] 1.2 接入 Run 生命周期、持有者跟踪、写回检测、取消与重启回收。
- [ ] 1.3 选择并接入一个真实固定路径 CLI，声明所有已知配置、缓存与临时目录。

## 2. 验收

- [ ] 2.1 在实际 Linux 运行真实工具与写回替身，覆盖原子替换、邻接文件、符号链接、越界、文件锁和双账户。
- [ ] 2.2 实测取消、工具或启动器异常、残留后代、更新、重启及清理，记录宿主与扫描范围。
