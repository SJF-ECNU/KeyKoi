## ADDED Requirements

### Requirement: 受控路径和写回

运行器 SHALL 在声明通过核验的 Linux 环境提供隔离配置视图，记录写回与可声明的持久化边界。

#### Scenario: 账户并发与原子替换

- **WHEN** 两个真实工具实例分别以不同账户写回同一个逻辑配置路径
- **THEN** 读取和写回各自隔离，宿主原文件未被覆盖，写回处置可追踪

### Requirement: 真实 CLI 与资源回收

运行器 SHALL 在取消、异常及重启后跟踪清理进程和受控资源，当前宿主缺少必要条件时拒绝文件模式。

#### Scenario: 取消或缺失能力

- **WHEN** 运行取消，或当前环境未达到登记的文件安全条件
- **THEN** 取消后资源清理或故障可诊断；未具备条件时不会生成普通磁盘明文
