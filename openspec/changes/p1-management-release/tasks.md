# P1 · 单机管理、安装与发布验收执行清单

验收依据为[规格场景](specs/standalone-management-release/spec.md)。本轮在当前 Mac 的原生 macOS 环境执行，见[验收口径](../../roadmap.md#验收口径)。

## 1. 实现

- [x] 1.1 完成管理 CLI、受保护的本机 UI 和导入、轮换、停用、接入及恢复操作。
- [x] 1.2 提供 macOS 安装包、后台启动和诊断步骤，在这台 Mac 验证安装、升级与重启。

## 2. 验收

- [x] 2.1 用真实代理客户端与运行时工具完成普通使用，复测许可拒绝、异常、锁定、升级和密文恢复。
- [x] 2.2 发布前整理本机 macOS 与工具版本的兼容记录、实测性能、流式与清理报告，按草案第 16.4 节逐项标注证据。
