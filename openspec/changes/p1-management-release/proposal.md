# P1 · 单机管理、安装与发布验收

## Why

单机版需要独立可安装，使用者能从录入、接入、验证一路走到轮换、锁定与故障恢复。

## What Changes

交付本机管理 CLI 和 Web UI、后台启动、安装包及实际工具验收报告。本轮交付与验收以本机 macOS 为准。

### Modified Capabilities
