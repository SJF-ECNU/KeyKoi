## 本机验收结果

新旧二进制比对与密文库一致性校验通过。用临时库分别演练密文恢复与旧版本回退，恢复后锁定、旧会话失效和授权待复核均正常，旧程序能用升级前副本启动并交付测试凭证。已在本机终端用主密码解锁试用版。

Git 远端读取、经 KeyKoi 的 GitHub CLI 认证请求、阿里云地域查询、SSH Agent 公钥枚举和本地签名验签均通过。GitHub 与阿里云的初测受测试命令的超时包装和终端进程组切换影响，改为无终端输入执行后通过。独立伪终端上的合成命令可正常退出。

签名助手在独立临时库完成真实 Keychain 登记、锁库和 Touch ID 解锁。确认返回的认证方式为 biometric，随后移除临时条目。
