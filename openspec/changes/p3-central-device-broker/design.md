# P3 · 多设备中心、许可与撤销设计

## Context

多设备需要共享权威存储并获得可撤销的用钥许可。中心故障或失联时，本机必须遵循明确截止时间。

## Goals / Non-Goals

交付 PostgreSQL 中心服务、受认证设备连接、中心存储与本机认证、中心认证执行、失效事件与断网规则。

## Decisions

- 中心负责权威凭证版本、设备会话和授权；终端通过服务接口请求，设备身份不使用业务凭证。本机认证仅在声明的可信节点内处理短期明文，中心认证由远端完成登记认证或签名。
- 在线确认失败即停止新用钥；短期模式以中心签发的绝对截止及保守剩余时长为上限，离线不续期。休眠恢复或时间异常须重新向中心确认。
- 轮换、停用和撤销传播版本化失效事件；事件丢失时由期限兜底。恢复中心备份后默认锁定并复核授权，变更授权代次以阻止历史会话或许可再续期。

- 本轮在同一 Mac 原生运行 PostgreSQL、中心服务和两个独立注册的设备客户端。客户端使用独立身份、端口和状态目录，通过重启或断开客户端与中心的连接验证故障行为。报告记录本机拓扑。
