# P3 · 多设备中心、许可与撤销执行清单

验收依据为[规格场景](specs/central-device-broker/spec.md)。本轮在当前 Mac 的原生 macOS 环境执行，见[验收口径](../../roadmap.md#验收口径)。

## 1. 实现

- [x] 1.1 实现 PostgreSQL 存储、受保护启动凭据、设备注册和受认证服务连接。
- [x] 1.2 复用 Broker 交付本机认证与中心认证路径，接通在线确认、短期许可和缓存。
- [x] 1.3 实现轮换、撤销通知及恢复后的授权复核与代次变化。

## 2. 验收

- [ ] 2.1 在本机 macOS 启动中心、PostgreSQL 和两个独立注册的客户端进程，验证两种认证路径、并发版本更新、在线撤销、丢事件、断连恢复、休眠与时间偏差。
- [x] 2.2 测量在线撤销传播时间、断网最长剩余许可和中心认证延迟，记录恢复前后会话行为。
