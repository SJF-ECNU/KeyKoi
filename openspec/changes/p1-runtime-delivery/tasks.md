# P1 · 原生 Helper 与环境变量交付执行清单

验收依据为[规格场景](specs/native-runtime-delivery/spec.md)。本轮在当前 Mac 的原生 macOS 环境执行，见[验收口径](../../roadmap.md#验收口径)。

## 1. 实现

- [x] 1.1 把 P0 Helper 接上受认证 IPC 和交付许可，避免在日志、错误或管理命令返回真实值。
- [x] 1.2 实现环境注入、原命令启动与取消，保留终端语义及诊断信息。

## 2. 验收

- [x] 2.1 用真实 Helper 和仅靠环境变量的 CLI 各运行一次，检查约定缓存目录、父 shell、参数和日志。
- [x] 2.2 覆盖上游失败、取消、异常退出、启动器退出、残留子进程、写回、并发账户、凭证更新和服务重启。
