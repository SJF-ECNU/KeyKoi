# P0 · 用钥协议、HTTP 与真实 Helper 原型执行清单

验收依据为[规格场景](specs/broker-gateway-helper-prototype/spec.md)。本轮在当前 Mac 的原生 macOS 环境执行，见[验收口径](../../roadmap.md#验收口径)。

## 1. 实现

- [x] 1.1 建立最小 Go 工程和测试入口，写明 Credential、Binding、Session、UseLease 字段与三种期限的区别。
- [x] 1.2 实现内存 Broker、许可校验、登记路由和一类 Header 注入，确保代理和 Helper 分别按模式授权。
- [x] 1.3 接入真实 Helper，用受控上游确认认证请求，按实际工具行为记录 stdout、stderr 与缓存路径。
- [x] 1.4 编写可复测的直连与代理测量命令，并提供交付模式与验证状态的展示文案。

## 2. 验收

- [x] 2.1 运行 HTTP 链路，验证正常注入、过期或越模式拒绝、错误目标无凭证以及首块先于完整响应返回。
- [x] 2.2 运行真实 Helper 并扫描约定路径，记录实际工具版本、系统、通道、扫描范围与限制。
- [x] 2.3 在相同环境运行直连和代理测量，保存时间分位数或样本统计，以及冷连接、热连接和流式结果。
