# P1 · 本机会话、授权 Broker 与审计执行清单

验收依据为[规格场景](specs/local-session-broker/spec.md)。本轮在当前 Mac 的原生 macOS 环境执行，见[验收口径](../../roadmap.md#验收口径)。

## 1. 实现

- [x] 1.1 建立 macOS 上的受认证 IPC 和控制面权限，在本机验证访问边界。
- [x] 1.2 实现 Session、Grant、UseLease、令牌与内部 Resolver，接通 Vault 的完整版本读取。
- [x] 1.3 实现锁定、停用、轮换失效与审计，区分不可用、过期和模式越权。

## 2. 验收

- [x] 2.1 验证无会话、过期、只持引用、越模式、非管理主体、锁定和重启等拒绝路径。
- [x] 2.2 检查版本切换与撤销后的下一次用钥和审计内容，登记本机 macOS 实际通过的本地身份验证方式。
