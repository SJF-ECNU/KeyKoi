# P1 · 显式 HTTP 网关执行清单

验收依据为[规格场景](specs/explicit-http-gateway/spec.md)。本轮在当前 Mac 的原生 macOS 环境执行，见[验收口径](../../roadmap.md#验收口径)。

## 1. 实现

- [x] 1.1 使用生产 Broker 接入受限令牌、路由鉴权、目标校验和三种首批 Header 注入。
- [x] 1.2 实现转发、取消和响应刷新，明确不支持的协议与错误语义。

## 2. 验收

- [x] 2.1 用受控上游核对目标、令牌移除、路径编码、重复参数、异常和分块时序。
- [x] 2.2 用真实 HTTP 客户端完成一条原命令代理工作流，记录工具、版本、系统及直连与代理的可比测量。
