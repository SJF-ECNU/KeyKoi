# 工具接入易用性

[[project-memory/工作流/工具接入易用性|对应工作流]]

## 目标与范围

让现有接入的安装、停机诊断与配置漂移撤销有可执行的下一步。保留受管命令的认证要求、前置参数约束与漂移保护。

## 方案

连接本地 IPC 失败时沿用原始错误，附上状态检查和离线列出原工具的方式。阿里云原生版本和本地配置检查通过安装记录中的绝对路径执行。安装发现旧明文配置时提醒用户检查隔离参数，提醒原生配置操作使用原工具绝对路径。撤销 Drift 时由服务端返回路径、区段、字段及恢复原受管值的指引。

## 验证

见[执行清单](tasks.md)。两套阿里云验收使用真实二进制的明确路径，避免拾取当前 Mac 正在使用的旧 shim。测试使用合成凭证与本机受控上游。
