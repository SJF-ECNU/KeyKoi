# 让工具接入错误可恢复

## Why

阿里云 CLI 接入后，原命令名优先命中 KeyKoi。停机时的连接错误缺少本地配置和版本检查的操作路径。撤销接入遇到配置漂移时也缺少受影响字段和恢复步骤。

## What Changes

- 在 shim 连接不到本地守护进程时提供状态检查和离线查看原工具路径的提示。
- 让 shim 安装提示指向原工具和既有接入记录。
- 在撤销遇到漂移时标明配置文件、区段、字段和恢复办法。
- 用真实阿里云 CLI 和 AWS CLI 在隔离数据中验证接入、离线查看与撤销。

## Capabilities

- `managed-tool-integration`：工具接入、停机诊断与撤销恢复。
