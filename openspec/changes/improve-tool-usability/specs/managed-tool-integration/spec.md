## ADDED Requirements

### Requirement: 受管命令停机诊断

受管 shim 在连接不到本地守护进程时 SHALL 以非零状态退出，并指向状态诊断以及离线查看原工具路径的入口。

#### Scenario: 守护进程已停止

- **WHEN** 阿里云受管 shim 需要连接已停止的 KeyKoi 守护进程
- **THEN** 用户可以从错误中找到状态检查命令，使用离线接入记录定位原工具，并通过原工具查看本地配置和版本

### Requirement: 撤销配置漂移时的恢复指引

撤销接入遇到受管配置值已变化时 SHALL 返回 `CONFIG_DRIFT` 和受影响的配置位置，保留用户修改与恢复材料。

#### Scenario: 用户编辑了受管字段

- **WHEN** 用户修改受管字段后请求撤销接入
- **THEN** 错误指出配置文件、区段和字段，用户可以恢复上次写入的受管值后正常撤销
